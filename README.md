# Portfolio Web

Mi página de **portfolio personal** está creada con [Astro](https://astro.build/), donde muestro
mis proyectos, stack tecnológico y formas de contacto.

## ✨ Características

- Diseño responsive y ligero
- Secciones de presentación, proyectos, stack y contacto
- Componentes reutilizables con Astro
- Estilos modernos con Tailwind CSS

## 📌 Tecnologías utilizadas

- Astro
- TypeScript
- Tailwind CSS

## 🚀 Cómo ejecutar en local

```bash
npm install
npm run dev
```

Luego abre `http://localhost:4321` en tu navegador.
